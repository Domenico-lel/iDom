# iDom

iDom è un hub personale nativo per iPhone, costruito in SwiftUI con un'interfaccia pulita e coerente con iOS.

## Moduli
- PC Remote
- Rete
- Quick Copy
- Parcheggio
- Scadenze

## Requisiti
- iOS 17+
- Xcode
- XcodeGen (`brew install xcodegen`)

## Avvio
```bash
xcodegen generate
open iDom.xcodeproj
```

Seleziona il tuo team personale in Signing & Capabilities, collega l'iPhone e avvia l'app.

## Stato
Versione iniziale: **0.1.0**. La struttura padre e il catalogo modulare sono pronti; i singoli strumenti verranno implementati progressivamente.
